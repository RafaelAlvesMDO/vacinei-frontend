# VACINEI!? - Front-end Repository

Repositório que concentra as aplicações front-end da plataforma **VACINEI!?** (Trabalho de Conclusão de Curso - CESMAC).

## 📁 Estrutura do Projeto

- **[`web/`](./web)**: Gerenciador Web administrativo voltado para profissionais de saúde e administradores (React 19 + TypeScript + Vite + Tailwind CSS v4).
- **[`mobile/`](./mobile)**: Aplicativo móvel voltado para os cidadãos.

## 🚀 Como Executar o Web Manager

Acesse o diretório `web` e instale as dependências:

```bash
cd web
npm install
npm run dev
```

O painel estará disponível por padrão em `http://localhost:5173`.
Certifique-se de que a API backend do Vacinei está em execução (porta padrão `3333`).
